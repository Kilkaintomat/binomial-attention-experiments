# Проверка влияния состава обучающих данных

Новая отдельная серия, подготовленная до её обучений и тестовых предсказаний. Текущая fair-v3 серия не меняется. Термин curriculum в имени версии обозначает серию о длинах; во всех режимах распределение фиксировано с первого шага, последовательного расписания усложнения нет.

## Сравнения

Одна архитектура F4-binomial: четыре независимых блока, r=4, width128, heads4, без inner-MLP. ER и DAG, пять seeds11,23,37,53,71. По30000 обновлений, batch64, исходный optimizer/scheduler. LR фиксируется по завершённому исходному выбору для F4-bin отдельно по семейству; новый поиск LR не проводится. Инициализация обучаемых параметров, число шагов и LR совпадают с исходными контролями.

| Режим | Данные | Новых обучений |
|---|---|---:|
| A: исходный | Исходный train n16/17 и исходная частота классов | 0; повторно используются10 checkpoint_last на30000 шагов |
| B: class_balanced | Тот же train, равная вероятность положительного/отрицательного запроса | 10 |
| C: short_aug | Половина запросов из B; половина из нового пула n48, преимущественно короткие положительные пути | 10 |
| D: length_balanced | Та же смесь размеров и тот же новый пул, что C; длины синтетической части равномерно1–16 | 10 |

Итого30 новых финальных обучений и10 исходных контролей. Новые короткие GPU-проверки являются техническими, а не дополнительным подбором гиперпараметров.

A→B оценивает баланс классов. C→D оценивает изменение распределения длин при одинаковом новом пуле графов и доле увеличенных графов. B→C меняет размер, структуру и сложность отрицательных примеров одновременно; эту разницу нельзя приписывать исключительно длине или размеру.

В B/C/D классы имеют равную вероятность, без требования ровно32/32 в каждом случайном batch. В C длины1–8 синтетических положительных пар выбираются по эмпирическому распределению коротких положительных путей исходного train данного семейства. В D синтетическая длина равномерна1–16, эквивалентно равным долям диапазонов1–4,5–8,9–12,13–16. Отрицательный запрос берётся из парной конструкции той же длины; длина отрицательного пути не определяется.

## Дополнительный пул

Для каждого семейства и каждой длины1–16 создаётся1024 графа n48. Две зеркальные цепи, мост от конца первой к концу второй; положительный запрос направлен по первой цепи, отрицательный начинается на второй и заканчивается в конце первой. Дополнительные вершины образуют входящие ветви и альтернативные двухшаговые маршруты без сокращения кратчайшего пути. Для циклического варианта добавляются зеркальные обратные рёбра. Проверяются BFS-метки, кратчайшая длина, одна слабая компонента и равные степени двух источников.

Дополнение для ER-training является управляемым циклическим генератором, а не графами из распределения Erdős–Rényi. Дополнение для DAG-training ациклично. Новые данные и их генератор явно помечаются отдельно от исходной выборки. Исходные данные неизменны.

Пул C/D общий; различаются только вероятности выборки длин. Дополнительный validation-пул:128 графов n48 на каждое семейство/длину, независимый от train. Его метки могут использоваться для отдельно объявленной калибровки, но не для выбора LR или checkpoint. Проверяется отсутствие точных совпадений размеченных матриц смежности между новыми split и со старыми данными соответствующего размера. Изоморфная независимость не утверждается.

## Обучение и выбор checkpoint

Все30 новых моделей обучаются с нуля. Основной результат использует checkpoint_last ровно после30000 шагов; ранний выбор checkpoint не смешивается с эффектом данных. Существующие исходные контролли используются на том же шаге30000. Исходная validation n18/19 проверяется каждые1000 шагов как мониторинг; её значения не запускают автоматическую замену режима или увеличение числа шагов.

CPU-проверки включают oracle, направление маски, воспроизводимость sampler, его вероятности, одинаковый пул C/D и раздельность split. GPU-проверки включают конечность градиентов, точное продолжение из checkpoint и длительное профилирование реального sampler. Полная сетка допускается при оценке с20% резервом в пределах отдельно одобренного бюджета. Короткие слоты, одна GPU на эту серию; расход считается по Slurm. Данные старых серий подключаются только для чтения.

## Проверки без обучения после постановки новой серии

1. Калибровка исходных готовых моделей по исходной validation и пересчёт старых тестовых метрик. По возможности используются calibration-предсказания уже работающей fair-v3 серии, без повторного GPU-инференса.
2. Подготовка общего нового теста и оценки при r=4,8,16,32 с неизменными обучаемыми весами. Предсказания на новом тесте открываются только после фиксации всех40 checkpoints новой серии. Изменение r сравнивается отдельно от изменения обучающей выборки.

Новый random far: ER/DAG, n64/128/256, по500 графов и8 запросов. Новый stress n256: длины8,12,16,20,24,32,48,64, plain DAG/cyclic и DAG/cyclic с входящими ветвями и альтернативными маршрутами; по100 шаблонов и2 парных запроса. Основной перенос по длине оценивается на ℓ>16. Длины8/12/16 являются контролем известных длин на больших графах.

Основная метрика BA при logit≥0; отдельно recall, specificity, AUROC, BCE, доля полностью правильных пар и распределение парного зазора. Дополнительные пороги выбираются только на заранее заданной validation: исходной и расширенной n48, раздельно. Ни один порог не подбирается по test. Все пять seeds сохраняются; парные сравнения B−A и D−C объявлены основными исследовательскими контрастами. Стоимость измеряется отдельно: равное число обновлений не означает равенства FLOPs при разных размерах графа.
